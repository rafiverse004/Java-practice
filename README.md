# Java Practice

A collection of Java programs, examples, and exercises created while learning Java. This repository is organized by topic to help reinforce core concepts and track learning progress.

## Features

* Beginner-friendly Java programs
* Organized topic-wise structure
* Practical examples and exercises
* Easy to read and extend

## Topics Covered

* Java Basics
* Variables and Data Types
* Operators
* Input and Output
* Conditional Statements
* Loops
* Methods
* Arrays
* Strings
* Object-Oriented Programming (OOP)
* Constructors
* Inheritance
* Polymorphism
* Abstraction
* Encapsulation
* Exception Handling
* Collections Framework
* File Handling
* Generics
* Multithreading
* Java 8+ Features (as added)

## Prerequisites

* Java JDK 17 or later (or the version you are using)
* Any Java IDE (IntelliJ IDEA, Eclipse, VS Code) or a terminal

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/rafiverse004/Java-practice.git
cd java-practice
```

### Compile a Java Program

```bash
javac FileName.java
```

### Run a Java Program

```bash
java FileName
```
